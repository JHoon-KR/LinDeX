# WebUI 안내

[English](../WEBUI.md) | [한국어](WEBUI.md)

LinDeX WebUI는 일반 설치와 모니터 세션 사용을 위한 지원 제어 화면입니다.
최종 사용자는 컴포지터 바이너리를 복사하거나, 모듈 상태를 편집하거나, Android
저장소에서 프로필 압축 파일을 찾을 필요가 없어야 합니다.

## 주요 제어

- **프로필:** Archcraft Sway Free, LXQt + stock labwc, XFCE + stock labwc.
- **Sway 테마:** Archcraft Sway Free를 선택하면 **공식 Dark**(기본값),
  **공식 Light**, **Pywal 자동 생성** 중 하나를 선택합니다. Pywal은 다음 시작 때
  번들 또는 사용자 배경화면에서 색상을 만듭니다.
- **지금 시작 / 중지:** 선택한 프로필을 준비하고 범위가 제한된 컴포지터
  프로세스 그룹과 DRM lease 하나를 소유합니다.
- **해상도와 주사율:** 연결된 모니터에서 모드를 읽습니다. 수동 100/120/144Hz
  선택은 실험적입니다.
- **DP 자동 시작:** 물리 DP와 checksum-valid EDID가 모두 있을 때만 준비된
  프로필을 시작합니다.
- **XWayland:** 필요할 때 레거시 X11 앱 지원을 켭니다.
- **휴대폰 터치 공유:** 기본값은 꺼짐이며, 사용자가 명시적으로 바꾸지 않으면
  내부 터치스크린은 Android에 남습니다.
- **USB 독 입력:** `linux-exclusive`는 활성 모니터 세션 동안에만 대상 USB
  키보드, 마우스, 간접 터치패드 event node를 grab합니다. `shared`는 두 환경에
  모두 보이게 합니다.
- **Mesa:** **KGSL + 패치 Turnip**이 권장 기본값이며 KGSL OpenGL/GLES와 패치된
  Turnip Vulkan이 이미 들어 있는 기본 Mesa 압축 파일 하나만 사용합니다.
  **KGSL + 비패치 Turnip**은 기본 Turnip이 작동하지 않을 때만 별도 호환
  덮어쓰기를 적용합니다. 하드웨어 Vulkan 검사는 KGSL GLES로 자동 폴백합니다.
- **출력 modifier:** 새 설치의 기본값은 `UBWC 우선`이며 exact-device 검증을
  통과한 경우에만 활성화됩니다. 검증 실패 시 원래 장치 형식을 유지합니다.
  `auto`는 기존 선택을 유지하고 검증된 XB24/QCOM 후보만
  추가합니다. 호환성 우선이며 UBWC를 우선 선택하지는 않습니다. `LINEAR`는
  modifier를 끄고, `UBWC 우선`은 정확히 검증된 장치 경로를 좁혀 적격 전체화면
  앱이 XB24/QCOM을 고르게 합니다. 일반 XR24 합성 데스크톱을 UBWC로 바꾸지는
  않습니다.
- **직접 스캔아웃:** `auto`는 컴포지터가 판단하고 `off`는 호환 모드입니다.
  강제 활성화 선택은 없습니다. 이 항목은 장면 적격성을 제어하며 출력 버퍼
  형식 우선순위를 제어하지 않습니다.
- **비디오 가속:** 현재 live 코덱 capability가 노출하는 정책을 선택합니다.
  지원되지 않는 엄격 경로는 사용할 수 없습니다.

## 첫 시작 단계

진행 화면에는 rootfs 검사, 프로필 자산 검사, Debian 패키지 설치, 설정, Mesa
설정, 브리지 준비 상태가 표시될 수 있습니다. Archcraft Sway Free는 릴리스에
포함된 checksum 고정 Archcraft 공식 공개 설정/외형 자산을 사용하며 Ko-fi
archive를 요구하지 않습니다. DP를 다시 연결하거나
재시도하기 전에 `ready` 또는 구체적인 실패 상태가 나올 때까지 기다리세요.
무작정 반복 시작하면 첫 번째 유용한 오류를 놓칠 수 있습니다.

WebUI는 전체 기기 로그 대신 짧고 정리된 상태를 표시합니다. release 패키지는
영구 설정/세션/코덱 로그를 보존하지 않습니다. 진단이 필요한 문제는 같은 dev
패키지로 한 번 재현하고 크기가 제한된 관련 부분만 수집하며 token, serial,
관련 없는 기기 데이터를 제거하세요.

## 안전한 사용 순서

1. DP를 물리적으로 분리한 상태에서 설치하거나 업데이트합니다.
2. Android를 일반 재부팅해 root 모듈을 활성화합니다.
3. WebUI를 열고 빌드 flavor와 rootfs 상태를 확인합니다.
4. 프로필을 선택합니다. Sway에서는 Dark, Light, Pywal 중 하나를 고른 뒤
   **지금 시작**을 누르고 설정이 끝날 때까지 기다립니다. Pywal은 설치된 공식
   script `~/.config/sway/theme/theme.sh --pywal`을 실행합니다.
5. 안내가 나오면 DP를 연결하고 디스플레이를 기다리는 상태가 아니라면 세션을
   시작합니다.
6. 업데이트, 모듈 제거, 위험한 실험 디스플레이 설정 변경 전에 세션을 중지합니다.

## 복구

모니터가 검거나 세션이 중지되지 않으면 DP를 분리하고 WebUI로 돌아가 **중지**를
누릅니다. 광범위한 프로세스 종료 또는 Android 디스플레이 명령을 실행하지
마세요. [문제 해결](TROUBLESHOOTING.md)과
[안전 및 복구](SAFETY.md)를 확인하세요.
